# Submissions

Every story on the site lives here, one folder per story:

```text
submissions/<section>/<slug>/index.md   + images
```

To submit, copy the `_template` folder in the section you want, rename it, fill it in and open a pull request. Full instructions: [CONTRIBUTING.md](../CONTRIBUTING.md).

- `unplanned-school/` — needs a `series`
- `unplanned-plan/`
- `unplanned-implementation/`

Folders starting with `_` are templates and are never published. Merging a pull request publishes every story in it that has `status: published` and a date on or before today.
